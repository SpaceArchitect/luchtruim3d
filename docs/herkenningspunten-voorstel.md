# Herkenningspunten: voorstel (21 nov, ter goedkeuring door Christian)

Toets per punt (archief, backlog sprint 2):
- **Z:** zichtbaar vanaf 1500–3000 ft;
- **U:** unieke vorm;
- **K:** staat op de ICAO-kaart of in de lesstof;
- **L:** landelijk toepasbaar via OSM-tags.

Doel: één à twee duidelijke punten per ±10 km, en niets wat die toets niet haalt.
